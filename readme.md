Functional Requirements

👉 Ye batate hain system kya karega (features, kaam).
Yani directly user ke liye visible actions.

Notes app me functional requirements example:

User register & login kar sake.

User new note create kar sake.

User apne notes dekh, edit aur delete kar sake.

Notes search ya filter kar sake.

➡️ Matlab: System ke functions / features.

🔹 Non-functional Requirements

👉 Ye batate hain system kaise chalega (quality, rules, performance).
Yani kaam karne ka tareeqa, na ke sirf kaam.

Notes app me non-functional requirements example:

REST API use karna data transfer ke liye.

App 2 second me response dena chahiye.

UI responsive ho (mobile + desktop pe).

Secure authentication (JWT, password hashing).

Code easily maintainable aur scalable ho.

➡️ Matlab: System ki qualities aur standards.
